# Flip 251 Charts

Design a custom exercise with basic chord progressions (ii–V–I, ii–V, iii–VI–ii–V, backdoor ii–V) through the keys, then send it to iReal Pro or save it as a PDF.

**Use it:** https://schemada.github.io/flip251-charts/

On iPhone or iPad, open the link in Safari, then Share → Add to Home Screen. On Android, Chrome ⋮ → Install app. It works offline after the first visit.
